# Help & Support

Open **Help & Support** from the top-right of the main WalkMark screen. The support screen includes local guidance for getting started, recording a walk, location permission, GPS troubleshooting, privacy, and contacting support.

Opening Help & Support does not collect or send data. WalkMark never automatically attaches walks, routes, locations, notes, photos, logs, device identifiers, or database contents to a support request.

If this build has a support email configured, **Contact support by email** opens the device email application with a basic message. Review and edit the message before sending it. If no address or compatible email application is available, WalkMark displays an unavailable message.
