# WalkMark — Navigation & Adaptive Layouts

## Screen Hierarchy
- **Main Journal View** (History list of past walks)
- **Active Walk View** (Map + live GPS stats + photo/note capture action)
- **Walk Detail View** (Route polyline, memories timeline)
- **Paywall Modal** (RevenueCat subscription options: weekly/annual)

## Adaptive Form Factors
- **Compact (Phones)**: Single-pane navigation.
- **Medium / Expanded (Tablets / Foldables / iPad)**: Two-pane layout with map on left and journal/memories on right.
