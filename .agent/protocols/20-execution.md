# 20 - Execution & Pass 2 Implementation

## Objective
Implement approved work in verified increments after human approval.

## Steps
READ -> IMPLEMENT -> VERIFY -> TEST -> REGRESSION CHECK -> UPDATE DOCUMENTATION.
Complete each success criterion before advancing to the next increment.

## Definition of Done
A feature is not DONE unless:
- Implementation complete
- Tests pass (unit, Compose UI, integration)
- QA review complete
- Technical documentation updated
- User manual updated if user-visible behavior changed
- Privacy/permission documentation updated when applicable
- Changelog updated
