# 10 - Planning & Pass 1 Gate

## Objective
Produce the smallest verifiable plan with explicit human approval gates.

## Trigger
Pass 1 feature investigation, structural change, or new requirement.

## Steps
1. Read before write and refresh relevant codebase context.
2. Analyze impact on KMP modules, Room schema, UI components, and monetization quota.
3. Define verifiable goals, automated tests, and rollback strategy.
4. Enforce STOP: Wait for human approval before proceeding to Pass 2.

## STOP rules
DO NOT write production code during Pass 1. Wait for explicit human validation.
